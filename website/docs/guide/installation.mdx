# Installation

## Prerequisites

Install and follow the guide at [react-native-paper](https://oss.callstack.com/react-native-paper/6.x/docs/guides/getting-started). This library requires **React** `>=19`, **React Native** `>=0.78`, and **React Native Paper 6** (`>=6.0.0-alpha.0 <7`). Paper 5 is not supported. If you are upgrading from a Paper 5-compatible release, see the [migration guide](./migration).

Also install **[react-native-safe-area-context](https://github.com/AppAndFlow/react-native-safe-area-context)** `>=5`.

This library also needs **[react-native-reanimated](https://docs.swmansion.com/react-native-reanimated/docs/fundamentals/getting-started/)** `>=4.3.0` and **react-native-worklets** `>=0.8.1`, with the Worklets Babel plugin. Paper 6 requires the same versions, so if you followed Paper's install guide you already have them.

`DatePickerInput` follows Paper 6's TextInput API (`variant`, `supportingText`, `endAccessory`).

# Input Date Picker

The input date picker provides a text field for typing a date, plus a calendar icon that opens a picker. On compact screens the icon opens a full-screen modal. On medium and expanded screens (width and height over 650) it opens a docked calendar under the field. Set `presentation` to `'docked'` for the [docked date picker](./docked-date-picker), which always anchors that calendar to the field. Typed text is kept as entered and formatted only after blur or submit. The field accepts `/`, `-`, `.`, and spaces, including a single-digit month or day. Supporting text shows the expected date format unless `supportingText` is set. Pass an empty string to hide it.

## Usage

```jsx playground
import { useState } from 'react';
import { View } from 'react-native';
import { DatePickerInput } from 'react-native-paper-dates';

export default function App() {
  const [inputDate, setInputDate] = useState(undefined);

  return (
    <View style={{ alignItems: 'center' }}>
      <DatePickerInput
        inputMode="start"
        label="Birthdate"
        locale="en"
        onChange={(d) => setInputDate(d)}
        value={inputDate}
        variant="outlined"
      />
    </View>
  );
}
```

## Props

**animationType**  
`Type: 'slide' | 'fade' | 'none' | undefined`  
The animation used when opening the date picker modal. Defaults to `'slide'` on iOS/Android and `'none'` on web.

**calendarIcon**  
`Type: string | undefined`  
Icon shown on the text field to open the modal. Defaults to `'calendar'`. Pass a name from [MaterialCommunityIcons](https://materialdesignicons.com/).

**disableCalendarIcon**  
`Type: boolean | undefined`  
When `true`, the calendar icon is disabled and cannot open the modal. Defaults to `false`.

**disableStatusBar**  
`Type: boolean | undefined`  
When `true`, the modal does not modify the status bar appearance or translucency. Defaults to `false`.

**disableStatusBarPadding**  
`Type: boolean | undefined`  
When `true`, skips safe-area top padding for the status bar in the modal. Defaults to `false`.

**endYear**  
`Type: number | undefined`  
The last year available in the year picker. Defaults to `2200`.

**hasError**  
`Type: boolean | undefined`  
Forces error styles on the input.

**hideValidationErrors**  
`Type: boolean | undefined`  
Hides built-in validation error styles and helper text.

**iconColor**  
`Type: string | undefined`  
Color of the calendar icon.

**iconSize**  
`Type: number | undefined`  
Size of the calendar icon in pixels. Defaults to `24`.

**iconStyle**  
`Type: StyleProp<ViewStyle> | undefined`  
Style applied to the calendar icon.

**inputEnabled**  
`Type: boolean | undefined`  
Whether the text field is editable. Behaves similarly to `disabled`. Defaults to `true`.

**inputMode (Required)**  
`Type: 'start' | 'end'`  
Whether the value should be treated as a start-of-day or end-of-day date.

**label**  
`Type: string | undefined`  
Label displayed on the text field.

**locale (Required)**  
`Type: string`  
Locale used for formatting and translations (for example `'en'` or `'de'`).

**variant**  
`Type: 'filled' | 'outlined' | undefined`  
Paper 6 TextInput variant. See [react-native-paper TextInput](https://oss.callstack.com/react-native-paper/6.x/docs/components/TextInput/TextInput).

**onChange**  
`Type: (date: Date | undefined) => void`  
Called when a valid date is committed on blur or submit, or confirmed from the picker.

**onChangeText**  
`Type: (text: string | undefined) => void`  
Called when the underlying text input value changes.

**onValidationError**  
`Type: ((error: string | null) => void) | undefined`  
Called with validation error messages, or `null` when valid.

**presentation**  
`Type: 'auto' | 'modal' | 'docked' | undefined`  
Which picker the calendar icon opens. Defaults to `'auto'`.

- `'auto'`: Docked calendar when both window dimensions are over 650; otherwise the full-screen modal.
- `'modal'`: Always open `DatePickerModal`.
- `'docked'`: Always open the [docked date picker](./docked-date-picker), a 360dp calendar anchored under the field.

**presentationStyle**  
`Type: 'pageSheet' | 'overFullScreen' | undefined`  
iOS modal presentation style. Defaults to `'overFullScreen'`.

- `'overFullScreen'`: Full-screen overlay (default).
- `'pageSheet'`: Card-style sheet. On iPad (width and height > 650pt), `DatePickerModal` automatically uses `formSheet` for a better fit.

**saveLabel**  
`Type: string | undefined`  
Confirm button label. The compact modal defaults to `save` (English: `'Save'`). The docked picker and the large-screen dialog default to `confirm` (English: `'OK'`) when this is omitted.

**saveLabelDisabled**  
`Type: boolean | undefined`  
Disables the confirm button in the modal. Defaults to `false`.

**startWeekOnMonday**  
`Type: boolean | undefined`  
When `true`, the calendar grid starts on Monday. Defaults to `false`.

**startYear**  
`Type: number | undefined`  
The first year available in the year picker. Defaults to `1800`.

**supportingText**  
`Type: string | undefined`  
Text under the field. Defaults to the expected date format. Pass `''` to hide it, or another string to replace the format. A validation error replaces this text unless `hideValidationErrors` is set.

**uppercase**  
`Type: boolean | undefined`  
Whether modal action labels are uppercased. Defaults to `false`.

**validRange**  
`Type: {
  startDate?: Date,
  endDate?: Date,
  disabledDates?: Date[]
}`  
Limits which dates can be selected. Dates outside the range are grayed out.

**value (Required)**  
`Type: Date | undefined`  
The current date value.

**withDateFormatInLabel**  
`Type: boolean | undefined`  
When `true`, appends the expected date format to the label. Defaults to `false`. The same format is the field placeholder unless `placeholder` is set.

**withModal**  
`Type: boolean | undefined`  
When `false`, hides the calendar icon and modal. Defaults to `true`.

Also accepts other [react-native-paper TextInput](https://oss.callstack.com/react-native-paper/6.x/docs/components/TextInput/TextInput) props (except `value`, `onChange`, `onChangeText`, `inputMode`, and `endAccessory`, which is used for the calendar icon).

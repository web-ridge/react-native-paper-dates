# Range Date Input

The range date input opens a dialog on start and end fields. The calendar icon switches to a range calendar in the same dialog. Each field accepts `/`, `-`, `.`, and spaces, including a single-digit month or day. The dialog is centered and at most 328dp wide.

The calendar modal for a range is documented on the [range date picker](./range-date-picker) page. This component is the dialog that opens on the fields.

## Usage

```jsx playground
import { useState } from 'react';
import { View } from 'react-native';
import { Button, Text } from 'react-native-paper';
import { DatePickerModalInput } from 'react-native-paper-dates';

export default function App() {
  const [open, setOpen] = useState(false);
  const [range, setRange] = useState({ endDate: undefined, startDate: undefined });

  return (
    <View style={{ alignItems: 'center', gap: 12 }}>
      <Button mode="outlined" onPress={() => setOpen(true)}>
        Enter dates
      </Button>
      <Text>
        {range.startDate
          ? `${range.startDate.toDateString()} – ${range.endDate?.toDateString() ?? '…'}`
          : 'No dates entered'}
      </Text>
      <DatePickerModalInput
        endDate={range.endDate}
        locale="en"
        mode="range"
        onConfirm={({ endDate, startDate }) => {
          setOpen(false);
          setRange({ endDate, startDate });
        }}
        onDismiss={() => setOpen(false)}
        startDate={range.startDate}
        visible={open}
      />
    </View>
  );
}
```

## Props

**calendarIcon**  
`Type: string | undefined`  
Icon that switches from the text fields to the calendar. Defaults to `'calendar'`. Pass a name from [MaterialCommunityIcons](https://materialdesignicons.com/).

**disableWeekDays**  
`Type: number[] | undefined`  
Weekday indexes to hide from the calendar (for example `[0, 6]` to hide Sunday and Saturday).

**endDate**  
`Type: Date | undefined`  
The currently selected end date.

**endLabel**  
`Type: string | undefined`  
Label on the end field. Defaults to the locale translation for `endDate` (English: `'End date'`).

**endYear**  
`Type: number | undefined`  
The last year available in the year picker. Defaults to `2200`.

**locale (Required)**  
`Type: string`  
Locale used for formatting and translations (for example `'en'` or `'de'`).

**mode (Required)**  
`Type: 'single' | 'range'`  
Selection mode. Use `'range'` for this picker.

**onConfirm (Required)**  
`Type: (params: { startDate: Date | undefined, endDate: Date | undefined }) => void`  
Called when the user confirms the range. The confirm button stays disabled while either field is invalid, and when the start and end dates are the same day.

**onDismiss (Required)**  
`Type: () => void`  
Called when the dialog is dismissed.

**saveLabel**  
`Type: string | undefined`  
Confirm button label. Defaults to the locale translation for `confirm` (English: `'OK'`).

**saveLabelDisabled**  
`Type: boolean | undefined`  
Disables the confirm button. Defaults to `false`. The button is also disabled while either field is invalid, and when the start and end dates are the same day.

**startDate**  
`Type: Date | undefined`  
The currently selected start date.

**startLabel**  
`Type: string | undefined`  
Label on the start field. Defaults to the locale translation for `startDate` (English: `'Start date'`).

**startWeekOnMonday**  
`Type: boolean | undefined`  
When `true`, the calendar grid starts on Monday. Defaults to `false`.

**startYear**  
`Type: number | undefined`  
The first year available in the year picker. Defaults to `1800`.

**uppercase**  
`Type: boolean | undefined`  
Whether header, field, and action labels are uppercased. Defaults to `false`.

**validRange**  
`Type: {
  startDate?: Date,
  endDate?: Date,
  disabledDates?: Date[]
}`  
Limits which dates can be confirmed. Dates outside the range fail validation.

**visible (Required)**  
`Type: boolean`  
Whether the dialog is shown.
